SQL Injection 防禦

❌ 不安全

sql = "SELECT * FROM users WHERE name = '" + user + "'";

將使用者輸入直接拼接到 SQL。

✅ 建議

SELECT * FROM users
WHERE name = ?;

使用 Prepared Statement / Parameterized Query。

安全開發檢查表

  • 使用參數化查詢
  • 限制資料庫帳號權限
  • 安全處理錯誤訊息
  • 輸入驗證與合理長度限制
  • 記錄異常事件並監控
  • 定期更新框架與資料庫元件

不要只依賴黑名單

單純封鎖幾個字串或符號不是可靠的主要防禦措施。安全設計應從資料與程式碼的邊界開始。
