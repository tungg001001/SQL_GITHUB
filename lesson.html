SQL Injection 原理

SQL Injection（SQL 注入）是當應用程式沒有正確分離「資料」與「SQL 語法」時，可能產生的安全漏洞。

正常查詢

SELECT * FROM users
WHERE username = 'alice'
AND password = '1234';

使用者輸入應該只被視為資料。

漏洞成因

如果程式直接把使用者輸入字串拼接進 SQL，特殊字元可能改變原本查詢的語意。

使用者輸入→字串串接→SQL Parser→Database

可能影響

  • 繞過錯誤的驗證邏輯
  • 未授權讀取資料
  • 資料遭竄改或刪除
  • 在特定架構下造成更嚴重影響

核心觀念

  • 輸入驗證不是唯一防線
  • 使用 Prepared Statement / Parameterized Query
  • 資料庫帳號採最小權限
  • 不要把詳細資料庫錯誤直接顯示給使用者
